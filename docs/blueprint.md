# **App Name**: DecorStyle Discovery

## Core Features:

- Style Quiz: Interactive quiz with a sequence of questions guiding the user to discover their home decor style preferences.
- Swoon-Worthy Selection: Image carousel where users select images that appeal to them to define initial style preferences.
- Room Focus Selection: Allows users to identify specific rooms they want to focus on for decor improvement.
- Email Collection: Gated content: collects user emails to provide custom style results and decor tips.
- AI Style Analysis: LLM tool assesses quiz responses to categorize user home decor style and create a style guide.
- Personalized Results Page: Displays style result incorporating user selections with supporting text

## Style Guidelines:

- Primary color: Soft sage (#A6C9A3), evokes nature, calm, and renewal.
- Background color: Light beige (#F5F5DC), provides a neutral and warm backdrop.
- Accent color: Muted gold (#B8860B), used sparingly for highlights and interactive elements.
- Body font: 'PT Sans', a versatile sans-serif for readability.
- Headline font: 'Literata', a transitional serif for elegance in titles.
- Line-art style icons in muted gold to represent various decor elements and styles.
- Clean, grid-based layout for balanced content presentation.
